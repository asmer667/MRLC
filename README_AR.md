# Neon Player 1.3.0 — مشروع Android مستقل

مشغل فيديو محلي وشبكي مبني باستخدام Kotlin وJetpack Compose. يستخدم هذا الإصدار AndroidX Media3 للتشغيل؛ دمج libmpv الأصلي ما زال عملاً منفصلاً ولم يكتمل بعد.

## المتطلبات
- Android Studio حديث أو بيئة بناء Gradle.
- JDK 17.
- Android SDK Platform 35 وBuild Tools 35.0.0.
- Gradle 8.13.

## البناء المحلي
من مجلد المشروع:

```bash
./gradlew --no-daemon :app:assembleDebug
```

على Windows استخدم `gradlew.bat --no-daemon :app:assembleDebug`. أول تشغيل ينزّل Gradle 8.13 تلقائياً، لذلك يحتاج اتصال إنترنت.

الناتج المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.

## البناء التلقائي على GitHub
الملف `.github/workflows/android-build.yml` يشغّل البناء عند push إلى `main` أو `master`، وعند Pull Request، ويمكن تشغيله يدوياً من تبويب Actions عبر `Run workflow`. بعد نجاح البناء، نزّل `NeonPlayer-debug` من Artifacts في تشغيل الـ workflow.

**مهم:** إضافة ملف workflow إلى ZIP لا تشغّل GitHub Actions وحدها. يجب رفع المشروع إلى مستودع GitHub ثم دفع commit إلى أحد الفرعين المذكورين أو تشغيل workflow يدوياً.

## الوظائف الموجودة في هذا الإصدار
- فهرسة فيديوهات الجهاز عبر MediaStore والبحث وعرض المجلدات.
- مفضلة ومواضع مشاهدة وقوائم تشغيل محفوظة محلياً.
- تشغيل عبر Media3 داخل `MediaSessionService` ليستمر بعد مغادرة واجهة التطبيق، مع إشعار وسائط النظام.
- اختيار مسارات الصوت والترجمة المضمنة، وإضافة ملف ترجمة خارجي عبر منتقي الملفات.
- وضع Picture-in-Picture تلقائياً عند مغادرة التطبيق أثناء التشغيل، مع دعم Android 8.0+.
- فتح روابط HTTP/HTTPS وHLS وDASH وRTSP بحسب دعم المصدر والترميز.
- إيماءات النقر المزدوج، الضغط المطوّل بسرعة قابلة للضبط من 0.20× إلى 4.00×، السحب للبحث، والتحكم العمودي بالصوت/السطوع، مع إعدادات محفوظة.
- بطاقات مجلدات تعرض فسيفساء من إطارات فيديو مصغرة حقيقية على Android 10+، مع عرض شبكي/قائمة/شجرة مبسطة وترتيب حسب الاسم أو عدد الفيديوهات أو الحجم.

## التخصيص في 1.3.0
- محرر ألوان داخل الإعدادات: اللون الأساسي والثانوي والخلفية عبر HEX، مع مجموعات ألوان جاهزة.
- وضع AMOLED بخلفية سوداء.
- أربعة أنماط لأيقونة المشغّل (Mint/Violet/Amber/Mono) عبر Activity Aliases؛ قد يتأخر تحديث شكل الأيقونة في بعض اللانشرات حتى تحديث الشاشة الرئيسية.
- تُحفظ الألوان ونمط الأيقونة محلياً.

## حالة محرك التشغيل
- هذا الإصدار ما زال يستخدم AndroidX Media3. لم يتم دمج libmpv بعد؛ لا تعتبره إصداراً مبنياً على mpv. راجع `LIBMPV_STATUS_AR.md` لخطة الدمج ومتطلباته.

## حدود يجب معرفتها
- دعم الشبكة هنا يعني روابط وسائط مباشرة وبروتوكولات Media3 المذكورة؛ لا يوجد حتى الآن متصفح SMB/NFS/SFTP أو اكتشاف DLNA/UPnP.
- الترجمة الخارجية تعتمد على MIME الذي يقدمه مزود الملفات؛ ملفات SRT هي الهدف الأساسي. ملفات ASS/SSA وفتح ملفات ترجمة متعددة تحتاج اختبارات وتوسعة إضافية.
- اختيار المسارات يتطلب أن يعلن ملف الوسائط عن المسارات وأن تكون مدعومة من Media3.
- PiP يحتاج Android 8.0 أو أحدث، وقد تختلف قيود الخلفية والإشعارات باختلاف إصدار Android والشركة المصنعة.
- لم يتم تأكيد نجاح تجميع APK في بيئة هذه الجلسة؛ يجب اعتبار أول تشغيل CI اختبار البناء الفعلي، وإصلاح أي خطأ يظهر في سجل Actions قبل وصف الإصدار بأنه مُتحقق منه.


راجع `PROJECT_STATUS.md` لمعرفة ما أُنجز وما لم يُنفذ بعد.
